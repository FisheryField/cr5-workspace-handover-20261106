## 当前判断

```text
标定请求       正常
伺服 calihome  正常
EtherCAT PDO   正常
主控写 JSON    正常
innerEncoder   读回为 0
重新使能计算   使用错误的零偏移，关节值跳变
```

因此本次实验进一步排除了“EtherCAT 总线断开”和“主控文件写入失败”。3.1.5 的问题位于伺服参数访问/返回路径，或者对应的厂商参数对象在该固件中不存在。
