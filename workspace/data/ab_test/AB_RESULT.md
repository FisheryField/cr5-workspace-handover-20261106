### 3.1 ① 上使能瞬间：只有 J6 跳

```
J6:  89.0045°  →  2.9165°     Δ = -86.0880°     ← 离散跳变
J1~J5: 完全不变
```

### 3.2 ② 标定：六轴全部归零

```
J1~J6 → 0.0000     ← 标定本身是成功的，J6 也被清零了
```

### 3.3 ④ 重新上使能：只有 J6 弹回

```
J6:  0.0082°  →  2.9229°     Δ = +2.9147°      ← 离散跳变
J1~J5: 不变（仅物理摇晃）
```

## 4. 为什么这是"因果"而不是"相关"

| 观察 | 说明 |
|---|---|
| **自变量被隔离到单轴** | 同一台控制器、同一次运行、同一批操作，只有 J6 的伺服固件版本不同 |
| **跳变是离散的，不是渐变的** | J6 在使能**那一刻**就从 0.0082 变成 2.9229；而 J1–J5 的 ±0.447° 是**渐变**的（物理摇晃） |
| **幅度差 6.5 倍** | J6 的 2.9229° vs J1–J5 的 0.447° |
| **符号模式不同** | J1–J5 的残差是 `+0.446, -0.447, -0.446, -0.443, +0.445` —— 典型刚体摆动在关节空间的映射；J6 是单轴常量偏移 |
| **两次使能重复出现** | ① 跳 −86.09°，④ 跳 +2.91°，两次都只发生在 J6 |

**⇒ 3.1.5.0 的驱动器在上使能时会把自己保存的零点重新套上，覆盖掉控制器刚做的标定。
3.2.D.8 接受并保持新零点。**

---

## 5. 附带确证的两件事

1. **"上使能时机械臂会晃动"这个解释被证实**：J1–J5 稳定后残差 `±0.447°`，五个轴等幅、符号交替，
   是刚体摆动的特征 —— 且是**渐变**的。用户当初对此的判断是对的。
2. **"J6 跳变"与摇晃是两回事**：J6 的 2.9229° 在使能瞬间就出现，不随摇晃衰减，量级大 6.5 倍。
