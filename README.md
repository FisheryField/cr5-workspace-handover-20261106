## 奇怪的bug1

有时候机械臂什么问题都没有上电后会莫名其妙红灯报错，这时候打开DobotStudio看看报错的内容，大概率是报IO上的错误，这个时候只需要拔掉控制柜那边的电源再插上重启就可以了。注意只是开关控制柜的按钮是没用的。

## 奇怪的bug2

在我重新修好机械臂后它虽然运动上不再有问题，且在车间实测同一轨迹中的坐标在实际的多次运动中机械臂到达的位置都是统一的。
但它有个非常奇怪的现象，如果出现运动中出现严重的事故导致其红灯报警且上电状态无法修复的情况且机械臂此时不在原点下选择下电重启，那么再度上电后机械臂一旦使能就会自己莫名奇妙上抬后下坠。此时需要将文件夹V1.3.4-stable中的RobotMaintenanceTools.exe将伺服固件刷到3.4.5.1以上的版本，再开机重启，机械臂就不再出现下坠的问题，此时通过DobotStudio将机械臂6轴运动到原点，再将伺服固件刷回3.1.5.0，再使用工作空间中的标零脚本对机械臂完成软件标零即可恢复正常。
注意DobotStudio自身的标零选项是无用的，3.1.5.0对应的伺服文件是CR5_Servo_ST_FOE_V3.1.5.0_UNVERIFIED.bin。
且记得每次下电前都需要将机械臂返回原点，否则也很可能会出现上述问题。
