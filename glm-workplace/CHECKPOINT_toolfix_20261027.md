## 实测根因与边界

接手时站内没有 TOOL 类型条目，机器人 PoseTool=identity，门把手为 OBJECT 类型。
无运动实验确认：选中 TCP 工具条目后，`robot.setPoseTool(eye(4))` 会改写该工具的定义；只重新选择原条目不能恢复它。另建 API 连接不会清零。
旧 v14w40 直发窗口会临时置零，finally 恢复异常被吞掉；进程被强杀也无法执行 finally。不能仅凭此断言接手时那次零值的唯一来源。
